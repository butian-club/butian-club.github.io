# 站点设置与倒计时

**站点设置**决定全站的默认表现——网站叫什么、要不要开放注册、默认什么语言和主题；
**比赛倒计时**则驱动首页的倒数展示。站点设置在后台配置，倒计时直接在首页管理。

- ⚙️ 站点设置：[https://gfssm.butian.club/admin/settings](https://gfssm.butian.club/admin/settings)
- ⏱️ 比赛倒计时：[https://gfssm.butian.club/](https://gfssm.butian.club/)（管理员在倒计时条中打开管理对话框）

## 站点设置

地址：[https://gfssm.butian.club/admin/settings](https://gfssm.butian.club/admin/settings)，
当前代码要求已激活的管理员账号；种子权限元数据将这项能力标记为 `settings:manage`。

可配置的项目：

| 设置项       | 键                                  | 说明                                           |
| ------------ | ----------------------------------- | ---------------------------------------------- |
| 网站名称     | —                                   | 站点主标题，支持**中英双语**两套文案           |
| 网站副标题   | —                                   | 站点副标题/口号，支持**中英双语**              |
| 首页欢迎语   | —                                   | 首页问候语，支持**中英双语**                   |
| 允许公开注册 | `auth.registrationEnabled`          | 是否开放注册入口（注册仍需邀请码）             |
| 注册需审批   | `auth.registrationRequiresApproval` | 有效邀请码注册后，是立即激活还是进入待审批状态 |
| 默认界面语言 | `ui.defaultLocale`                  | 新访客的默认语言                               |
| 默认主题模式 | `theme.defaultMode`                 | 默认亮/暗色主题                                |
| 品牌主色     | `theme.accentColor`                 | 全站强调色                                     |

这些设置影响**全站默认表现**，包括登录页、首页、注册开关等。

### 中英双语文案

网站名称、副标题、欢迎语都各有**中文、英文两套**。请两套都填写，
以便不同语言的访客看到匹配的文案；默认展示哪一套由 `ui.defaultLocale` 决定。

### 注册怎么把关

注册同时受三个条件控制：注册入口、邀请码和审批策略。

| `registrationEnabled` | 效果                                                         |
| --------------------- | ------------------------------------------------------------ |
| 开                    | 注册页可用；访客仍需一个**有效邀请码**才能注册               |
| 关                    | 注册页提示「当前已关闭公开注册」，新账号只能由管理员另行创建 |

`registrationRequiresApproval` 再决定有效注册的结果：

| 审批开关 | 新账号状态 | 使用范围                                   |
| -------- | ---------- | ------------------------------------------ |
| 关       | `ACTIVE`   | 立即进入资料完善与工作区                   |
| 开       | `PENDING`  | 只能进入等待页，管理员通过后才可使用工作区 |

邀请码仍可限制次数、有效期和预绑定部门。管理员在[成员目录](./members.md)发放 / 停用邀请码，
并处理待审批与已停用账号。

### 修改站点设置步骤

1. 打开 [https://gfssm.butian.club/admin/settings](https://gfssm.butian.club/admin/settings)。
2. 修改需要调整的字段（记得双语文案两套都填）。
3. 保存。设置随即对全站访客生效。

## 比赛倒计时

地址：[https://gfssm.butian.club/](https://gfssm.butian.club/)。管理员在首页倒计时条打开管理对话框。

配置后，**首页会自动倒数**到目标时间，营造比赛氛围、提醒进度。

可配置项：

| 字段              | 说明                 |
| ----------------- | -------------------- |
| 比赛名称（中/英） | 倒计时标题，双语     |
| 目标日期时间      | 倒数到的截止时刻     |
| 描述（中/英）     | 补充说明，双语       |
| 启用开关          | 是否在首页展示倒计时 |

### 配置倒计时步骤

1. 以管理员身份打开[首页](https://gfssm.butian.club/)，在倒计时条打开管理对话框。
2. 填写比赛名称、**目标日期时间**、描述（中英文各一份）。
3. 打开**启用开关**并保存。
4. 到 [首页](./dashboard.md) 确认倒计时已按预期展示。

:::tip
比赛结束或需要临时隐藏时，把**启用开关**关掉即可，无需删除已填内容，
下次沿用很方便。
:::

:::note
站点设置与倒计时的改动都会记录到 [操作日志](./audit.md)。
:::
