# 访问与登录

本页介绍如何打开平台、完成登录、在同一浏览器里切换多个账号，以及登录页上的外观设置。第一次接触平台，建议先读 [协作平台简介](./intro.md)。

## 打开平台

平台是一个中文界面、桌面端优先（同时兼容手机与平板）的团队后台，用浏览器即可访问，无需安装任何客户端。

- 🌐 访问地址：[https://gfssm.butian.club](https://gfssm.butian.club)
- 🔑 登录页面：[https://gfssm.butian.club/login](https://gfssm.butian.club/login)

推荐使用较新版本的 Chrome、Edge、Safari 或 Firefox。

## 登录

平台使用 **用户名或邮箱 + 密码** 登录（基于 Auth.js v5 的凭据登录）。邮箱是注册时的选填项；
没有填写邮箱的账号请使用用户名。

1. 打开 [https://gfssm.butian.club/login](https://gfssm.butian.club/login)。
2. 输入你的 **用户名或邮箱** 和 **密码**。
3. 点击登录按钮。
4. 登录成功后进入 **工作台（首页）**，即可开始使用。

:::note[还没有账号？]
平台账号需要一个 **邀请码** 才能注册。是否提交即用，由管理员当前设置的审批策略决定，
请参阅 [注册与邀请码](./register.md)。
:::

### 登录后可能出现的情况

账号有不同的状态，登录后的走向也不同：

| 账号状态               | 登录结果                                             |
| ---------------------- | ---------------------------------------------------- |
| **ACTIVE（已激活）**   | 正常进入工作台，可使用全部对应权限的功能             |
| **PENDING（待审批）**  | 可以登录，但只进入等待页；管理员通过后才能使用工作区 |
| **REJECTED（已拒绝）** | 无法登录，需要管理员重新处理账号状态                 |
| **DISABLED（已禁用）** | 无法登录，需联系管理员恢复                           |

各状态的详细含义与流转，见 [账号状态说明](./account-states.md)。

## 多账号切换

同一台电脑上如果使用多个账号，平台可保存账号提示，减少反复输入用户名的麻烦。

- 平台支持在 **同一浏览器** 内保存 **最多 3 个账号提示**。
- 通过顶栏的账号切换器选择身份后，仍需**重新输入该账号的密码**完成认证；平台不会在第二个
  Cookie 中保存可重放的登录会话。
- 正式退出会清除当前浏览器保存的认证信息和账号提示。

:::info[小提示]
如果你需要保存第 4 个账号，请先移除一个不再使用的账号，或改用浏览器的另一个配置文件 / 隐身窗口登录。
:::

## 登录页外观设置

登录页 **右上角** 有一个「外观」控件，可以在登录前就把界面调成你喜欢的样子。设置项包括：

| 设置项     | 可选值                 |
| ---------- | ---------------------- |
| **主题**   | 浅色 / 深色 / 跟随系统 |
| **品牌色** | 切换界面主色调         |
| **语言**   | 中文 / 英文            |

这些偏好会影响你看到的界面外观，可随时调整。

## 忘记密码怎么办

平台没有通过邮件自动重设密码的流程，但登录页提供公开的
[账号帮助](https://gfssm.butian.club/account-help?topic=password)表单。

:::warning[提交账号帮助申请]
填写账号或姓名、可联系你的方式与补充说明。申请会通知当前活跃管理员，由管理员核验后处理；
该表单本身不会自动修改密码。
:::

## 常见登录问题

| 现象                 | 可能原因与处理                                                                                      |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| 提示账号或密码错误   | 核对输入；注意大小写；仍不行请提交[账号帮助](https://gfssm.butian.club/account-help?topic=password) |
| 注册时提示邀请码无效 | 邀请码可能过期 / 用完 / 被停用，向管理员索取新码，见 [注册与邀请码](./register.md)                  |
| 登录后只能看到等待页 | 账号处于 **PENDING（待审批）**，见 [账号状态](./account-states.md)                                  |
| 完全无法登录         | 账号可能被 **REJECTED / DISABLED**，请联系管理员，见 [账号状态](./account-states.md)                |
| 想换个身份操作       | 使用顶栏账号切换器选择已保存提示，再输入对应密码                                                    |
