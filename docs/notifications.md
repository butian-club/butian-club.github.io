# 通知中心

通知中心把和你相关的事件（被指派任务、工单被创建或处理、评论等）集中起来，让你不用一个页面一个页面地去翻。它是 **站内通知**：只在平台内提醒，不发邮件、不发短信。

- 📥 通知中心地址：[https://gfssm.butian.club/notifications](https://gfssm.butian.club/notifications)

## 在哪里看通知

平台顶栏有一个 **铃铛图标 🔔**，无论你在哪个页面都能看到它。

- 有 **未读通知** 时，铃铛图标上会显示红色的**未读计数徽标**，超过 99 条显示 `99+`。
- 点击铃铛会直接进入通知中心；当前没有铃铛下拉预览。

:::tip[关于未读徽标]
计数徽标仅表示「有新事件」，不一定紧急。点开查看，处理完即可标记为已读、将计数清零。
:::

## 系统会自动提醒哪些事

你不需要手动订阅。平台会根据事件参与者自动确定接收人并创建站内通知。常见场景包括：

| 触发事件                   | 谁会收到                                         |
| -------------------------- | ------------------------------------------------ |
| 任务被创建、更新或添加进展 | 被指派用户、被指派部门成员、任务创建者等相关人   |
| 工单被创建                 | 所有已激活管理员                                 |
| 工单被指派或状态变化       | 被指派管理员、工单提交人                         |
| 工单出现新评论             | 工单提交人和当前处理管理员                       |
| 聊天消息包含有效 `@提及`   | 被提及的成员或部门成员                           |
| 文档首次发布               | 已激活管理员，以及与标书章节有映射的负责部门成员 |

具体能收到哪些事件，取决于你的角色与权限。关于任务与工单本身怎么用，见 [任务](./tasks.md) 与 [工单](./tickets.md)。

## 标记为已读

处理完一条通知后，把它 **标记为已读**，未读计数就会相应减少，铃铛徽标在没有未读时会消失。

1. 打开 [https://gfssm.butian.club/notifications](https://gfssm.butian.club/notifications)。
2. 在「全部 / 未读」之间切换；列表每页显示 20 条。
3. 点击单条通知的**查看**会在跳转时把它标为已读，也可以单独点击**标记已读**。
4. 需要一次清空计数时，使用页面顶部的**全部标为已读**。

:::note[已读只是状态，不会删内容]
标记已读只是把这条通知从「未读」变成「已读」，方便你清理计数。当前界面不会因此删除通知，
已读记录仍可在「全部」列表回看。
:::

## 关于「没收到通知」

如果你觉得某件事没有提醒到你，请先确认以下几点：

- 平台通知是 **纯站内** 的，请回到平台查看铃铛图标，而不是等邮件或短信。
- 你能收到某类事件，取决于你是否是该事件的相关人（例如任务是否指派给你、工单是否与你有关）。
- 如果确实应该收到却一直没有，可能是权限或指派对象设置的问题，可联系管理员核实。

:::warning[不要依赖通知做唯一提醒]
通知中心是辅助提醒，不是待办清单。重要任务请同时到 [任务](./tasks.md) 页面确认截止时间与进度，避免漏掉。
:::

## 常见问题

| 问题                   | 说明                                        |
| ---------------------- | ------------------------------------------- |
| 会发邮件 / 短信吗？    | 不会，只有站内通知                          |
| 需要自己订阅吗？       | 不需要，系统按事件参与者自动确定接收人      |
| 未读计数一直在怎么办？ | 打开通知中心，把已处理的通知 **标记为已读** |
| 标记已读会删除吗？     | 不会，记录仍可在「全部」列表回看            |
