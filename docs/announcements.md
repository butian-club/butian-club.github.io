# 公告

**公告（Announcement）**是社团面向全体成员「广播」重要信息的方式：报名截止、
集训安排、规则变更、临时通知等，都可以通过公告统一发布。公告可以置顶，
置顶后会排在首页公告列表前面，确保重要信息优先被看到。

:::note[权限速览]
**成员对公告只读**——可以阅读，但不能发布或修改。**发布和管理公告**属于管理动作，
当前代码要求管理员身份；种子权限元数据将它标记为 `announcements:manage`。
详见[角色与鉴权](./roles-permissions.md)。
:::

## 阅读公告

作为成员，你主要是**阅读**公告：

- 登录后，首页会显示最近的公告，**置顶公告优先**，其余公告按发布时间倒序排列。
- 每条公告直接显示标题、两行正文摘要、发布时间和置顶标记。
- 当前没有独立的公告列表或详情页，公告标题也不是详情链接；需要保留较长内容时，
  应发布为[文档](./documents.md)，再在公告中给出文档地址。

:::tip
养成登录后先查看首页置顶公告的习惯，比赛季的关键节点通常都会在这里通知，
避免错过截止时间等重要信息。
:::

## 置顶与首页展示

公告可以被标记为**置顶**。置顶的作用是提升可见度：

- 置顶公告会在 [首页](./dashboard.md) 显著展示，所有成员登录即可看到。
- 适合放最重要、最紧急、需要全员知晓的通知。

:::info
置顶开关由管理员控制。重要通知过期后，管理员通常会取消置顶，
让首页始终突出当前最相关的信息。
:::

## 正文格式与当前限制

公告表单中的字段名沿用 `contentMd`，但当前首页**按普通文本显示两行摘要**，
没有经过 Markdown 渲染。不要依赖标题、表格、任务列表或 Markdown 链接等语法表达关键信息。

一条集训通知应优先在开头写清：

- **时间**：几月几日几点
- **地点**：具体位置
- **需要做什么**：直接写清行动和负责人
- **截止时间**：不要只写“尽快”

较长的准备清单和相关资料应放到[文档](./documents.md)，公告只负责提示重点。

## 发布与管理（管理员）

发布和管理公告需要管理员权限（`announcements:manage`）。管理员可以：

| 动作                | 说明                           |
| ------------------- | ------------------------------ |
| **发布公告**        | 填写标题、正文和发布时间后发布 |
| **置顶 / 取消置顶** | 控制公告是否在首页突出展示     |
| **管理公告**        | 编辑、维护已有公告             |

发布公告的一般步骤：

1. 管理员在 [首页](./dashboard.md) 就能看到公告的**发布 / 编辑 / 删除**入口——公告管理
   直接在首页完成，不必单独进管理后台。
2. 填写标题和简明正文；较长内容放入文档，并附上文档地址。
3. 决定是否置顶——重要通知建议置顶到首页。
4. 发布后，已激活成员可在首页看到；系统还会尝试在聊天的[社团总群](./chat.md)
   播报标题和正文首行。聊天播报失败不会阻止公告发布。

:::warning
成员没有发布或修改公告的权限。如果你有需要全社知晓的信息，
可以联系管理员代为发布，或通过 [工单](./tickets.md) 提交你的诉求。
:::

## 写好公告的建议

- **标题点题**：首页没有详情页，让人只看标题和摘要就能理解重点。
- **信息完整**：时间、地点、需要做什么、截止到几点，一次说清。
- **善用置顶**：真正重要的才置顶，置顶太多等于没有重点。
- **及时清理**：过期通知及时取消置顶，保持首页整洁。

## 常见问题

- **我看不到「发布公告」入口？** 发布 / 管理公告需要 `announcements:manage`，
  成员默认只读。
- **首页没看到公告？** 可能暂时没有公告，或你的账号尚未激活，
  见 [账号状态](./account-states.md)。
- **公告和文档怎么选？** 一次性、需要全员及时看到的用公告（可置顶到首页）；
  需要长期查阅、沉淀的知识放 [文档](./documents.md)。
- **公告会触发站内通知吗？** 不会创建通知中心记录；公告通过首页展示，并在发布时尝试
  播报到社团总群。和自己相关的任务、工单事件提醒见 [通知中心](./notifications.md)。
