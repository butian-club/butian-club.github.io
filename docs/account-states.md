# 账号状态

每个账号都有一个状态，决定它能否登录和使用工作区。有效邀请码只证明注册凭据有效；
管理员可以另行开启“注册需审批”，让新账号先进入待审批状态。

## 四种账号状态

| 状态       | 名称   | 能否登录 | 说明                                           |
| ---------- | ------ | -------- | ---------------------------------------------- |
| `PENDING`  | 待审批 | 可以     | 只能进入 `/pending` 等待页，不能使用正式工作区 |
| `ACTIVE`   | 已激活 | 是       | 正常账号，可登录并使用其角色允许的全部功能     |
| `REJECTED` | 已拒绝 | 否       | 注册申请被拒绝，管理员可重新调整状态           |
| `DISABLED` | 已禁用 | 否       | 曾经激活、后被管理员停用，无法登录             |

**流转**：

- **审批关闭**：有效邀请码注册 → `ACTIVE`。
- **审批开启**：有效邀请码注册 → `PENDING`；管理员可通过为 `ACTIVE`，或拒绝为 `REJECTED`。
- 管理员可在[成员目录](https://gfssm.butian.club/members)将账号改为上述任一状态；
  常见停用与恢复流转是 `ACTIVE` ↔ `DISABLED`。

```
有效邀请码注册
  ├─ 不需审批 ───────────────▶ ACTIVE
  └─ 需要审批 ─▶ PENDING ─┬─ 通过 ─▶ ACTIVE
                           └─ 拒绝 ─▶ REJECTED

ACTIVE ── 管理员停用 ──▶ DISABLED
ACTIVE ◀─ 管理员恢复 ─── DISABLED
```

## 登录行为速查

| 状态       | 登录结果                       |
| ---------- | ------------------------------ |
| `PENDING`  | 允许建立会话，但被限制在等待页 |
| `ACTIVE`   | 正常登录，进入工作台           |
| `REJECTED` | 拒绝登录                       |
| `DISABLED` | 拒绝登录                       |

:::tip[相关操作在哪里]
审批、拒绝、禁用与恢复账号都由管理员在 [成员目录](./members.md) 完成；是否开放注册、
是否需要审批属于[站点设置](./settings.md)。
:::
