# 常见问题

这里用问答形式回答大家最常遇到的问题。找不到答案时，可以顺着每条里的链接深入，或直接联系社团管理员。

## 登录与账号

### Q：为什么我登不上？

A：常见原因包括：

- **账号待审批（PENDING）**：可以登录，但只能进入等待页。
- **账号被拒绝或禁用（REJECTED / DISABLED）**：无法登录，需要管理员重新处理状态。
- **账号或密码错误**：核对用户名 / 邮箱和密码；仍不行请提交账号帮助申请。

详见 [账号状态](./account-states.md)。

### Q：我想注册，却提示邀请码无效 / 没有邀请码？

A：平台始终要求管理员发放的有效邀请码。邀请码无效 / 过期 / 已用完 / 已停用时需要换码；
有效提交后是否立即可用，则取决于管理员的审批设置。见 [注册与邀请码](./register.md)。

### Q：忘记密码怎么办？

A：打开[账号帮助](https://gfssm.butian.club/account-help?topic=password)，填写账号或姓名、
可联系你的方式和补充说明。申请会通知管理员，由管理员核验后处理；不会自动重设密码。

### Q：能不能有多个账号？

A：同一浏览器最多保存 **3 个账号提示**。选择另一个账号后仍需输入对应密码重新认证；
平台不会把多个可重放会话保存在浏览器中。详见 [访问与登录](./access.md)。

## 权限与后台

### Q：为什么我看不到管理后台？

A：管理后台只对管理员开放。后台包含控制台、站点设置、AI 配置、附件与操作日志；倒计时在
首页内联配置。任务、工单、文档、部门、成员和公告的管理入口位于各自功能页面，仍只对管理员
开放。见 [管理后台总览](./overview.md)。

### Q：我应该有某个功能，但打不开？

A：当前代码主要按账号是否 `ACTIVE`、角色是否 `ADMIN`，以及任务指派、内容作者和频道成员关系
判断访问范围。数据库中的权限码是种子元数据，并非动态授权开关。参考
[角色与权限](./roles-permissions.md)。

## 使用与设置

### Q：手机能用吗？

A：可以。平台 **桌面端优先**，但同时兼容手机和平板，用手机浏览器即可打开 [https://gfssm.butian.club](https://gfssm.butian.club)。复杂操作（如编辑长文档）在电脑上体验更好。

### Q：怎么改主题和语言？

A：在 **外观设置** 里改。主题可选 浅色 / 深色 / 跟随系统，语言可选 中文 / 英文，还能自定义品牌主色。个人中心和登录页右上角都有外观控件，见 [个人中心与外观](./profile.md)。

### Q：为什么我没收到通知？

A：平台通知是 **纯站内** 的，不发邮件、不发短信。请回到平台看顶栏的铃铛图标是否有红点和未读计数；能收到哪些事件取决于你是否是相关人。详见 [通知中心](./notifications.md)。

### Q：在哪里记录我每天做了什么？

A：在个人中心（/profile）的 **工作日志** 里，用 Markdown 记录，可编辑可删除。见 [工作日志](./worklogs.md)。

### Q：怎么找到某位同伴、看他在不在线？

A：打开[成员目录](./members.md)可查看成员资料、部门、角色与在线状态。离线由系统自动判断；
成员可选择 **在线 / 专注中 / 请勿打扰**。看到“请勿打扰”时用聊天留言即可。

### Q：怎么和大家聊天？要手动加群吗？

A：打开侧边栏的聊天即可。系统会加入**社团总群**、**开放论坛**和你所在的部门频道；
点成员头像可发起私聊。聊天支持回复、转发、附件、@提及、投票、接龙、报名和搜索。
任务 / 工单 / 文档可从详情页分享到聊天，但当前没有“消息一键转任务 / 工单 / 公告”。

### Q：平台的 AI 助手在哪？

A：AI 助手在聊天中参与，不占成员名单。可用 `@ai`、`/ai`、直接称呼或回复 AI 来明确触发；
系统也可能在确有帮助时谨慎参与普通讨论。工具权限和高影响操作确认见 [AI 助手](./ai.md)。
